# Proposal

## Why

The repository should rank for searches around the JC3248W535 board, its AXS15231B panel
and the ESPHome media-player use case. The GitHub description and topics were generic, and
the README had grown long enough that the first screen was mostly tables. A shorter,
keyword-rich landing page with the details moved into a dedicated guide is easier to scan
and easier for search engines to index.

## What Changes

- Rewrite the repository description with board aliases, panel and use-case keywords.
- Extend the GitHub topics to the full set the repository can own (20 of 20).
- Shorten and restyle `README.md` with emoji, a tighter pitch, screenshots, install and a
  compact hardware table.
- Move the on-device UI, media preparation, entity table, dashboard cards and limitations
  into `docs/usage.md`.
- Link the new guide from `README.md` and `docs/README.md`.

## Capabilities

_None. This is a presentation and documentation change._

## Impact

- `README.md`, `docs/README.md`, new `docs/usage.md`.
- GitHub repository description and topics.
- No firmware, configuration or entity changes.
